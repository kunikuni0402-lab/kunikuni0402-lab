### Agent Execution Quality Research

An independent research project exploring how organizations can verify AI agents' reported task completion using execution evidence.

**Recent pilot — SWE-bench Evidence Validation**

- Retrieved publicly available predictions, evaluation reports, and execution logs from a SWE-bench Verified submission.
- Cross-checked 15 reported passing tests against their corresponding execution log entries for one evaluation instance.

*This was a small, independent evidence-validation pilot, not a full benchmark reproduction.*
